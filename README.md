About the task : 

This project is part of my academic internship, specifically Task 2, which required building a REST API client in Java to fetch and display real-time weather information of a specific city using a public API. The main objective of this task was to help me understand how to consume third-party APIs using Java, handle HTTP requests, parse JSON data, and display meaningful results to the user.

For this task, I chose to use the OpenWeatherMap API, a popular and freely available public weather API that provides current weather data for any city across the globe. I implemented the solution using Java, and the application was built, run, and tested using the IntelliJ IDEA IDE, which provided an efficient and user-friendly environment for writing and debugging Java code.

Features Implemented

Fetches real-time weather data from OpenWeatherMap for a fixed or user-defined city.

Displays key weather metrics such as:

Temperature

Feels like temperature

Weather description (e.g., Clear, Rain)

Handles API errors and no-internet scenarios using appropriate exception handling.

Can be extended to show additional details like humidity, wind speed, country, etc.

How It Works

The program sends an HTTP GET request to the OpenWeatherMap API endpoint with the specified city name and API key. It receives the weather data in JSON format, which is parsed using the org.json library. The relevant fields are extracted and printed to the console in a user-friendly format. The user only needs to run the program and see the output or, optionally, provide a custom city name as input.
